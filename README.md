# MailSender (WPF Application)

Учебный проект десктопного приложения для управления email-рассылками. 
> **Примечание:** Проект создан в 2021 году.

## Архитектура и особенности реализации
Проект разделен на слои для обеспечения слабой связанности и высокой тестируемости:

*   **`MailSender.lib`** — библиотека с бизнес-логикой, интерфейсами, базовыми классами (ViewModel, Command) и сервисами.
*   **`MailSender`** — клиентское приложение WPF (Views, ViewModels, XAML).
*   **`Tests`** — проект с юнит-тестами (xUnit).

**Ключевые решения:**
*   **Внедрение зависимостей:** Настроен контейнер через `IHost` (Microsoft.Extensions.Hosting), как в ASP.NET Core. Все сервисы и ViewModels регистрируются в `App.xaml.cs`.
*   **Паттерн MVVM:** Реализован с нуля без сторонних фреймворков (таких как Prism или MVVM Light). Включает в себя базовый класс `ViewModel` (с `INotifyPropertyChanged`), `ViewModelLocator` и кастомные реализации `ICommand`.
*   **Слоистая архитектура:** Работа с данными скрыта за интерфейсами (`IRepository<T>`), что позволяет легко подменить хранилище (в текущей версии используется in-memory репозиторий).
*   **Асинхронность и таймеры:** Для обновления статистики (время работы, количество писем) используются `System.Timers.Timer` и `Stopwatch`.

## Технологический стек
*   **Платформа:** C#, .NET (WPF)
*   **Архитектура:** MVVM, DI (Microsoft.Extensions.Hosting)
*   **Тестирование:** xUnit
*   **UI/UX:** XAML (Data Binding, Data Templates, Commands, Custom UserControls)

## Основной функционал
*   Управление списками серверов, отправителей и получателей.
*   Создание и редактирование шаблонов писем.
*   Планировщик задач (выбор даты и времени отправки).
*   Экран статистики (счетчик отправленных писем, время работы приложения).

## Как запустить
1. Клонируйте репозиторий.
2. Убедитесь, что у вас установлен .NET SDK (рекомендуется .NET 5 или 6).
3. Откройте решение `MailSender.sln` в Visual Studio.
4. Установите проект `MailSender` как запускаемый по умолчанию (Startup Project).
5. Нажмите F5 для сборки и запуска.
